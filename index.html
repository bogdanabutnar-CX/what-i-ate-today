Welcome to What I Ate

To sync your data across devices, this app uses a private GitHub Gist. You need a GitHub account and a personal access token with gist scope only.

Your token is stored only on this device and never in the app code.

Need a token? Go to github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token. Tick only gist.
